# Безопасность

Об уязвимостях сообщайте приватно через GitHub → Security → «Report a vulnerability», не создавайте публичный issue.

Принципы проекта: `contextIsolation`, `sandbox`, без `nodeIntegration`; узкий preload-API; токены хранятся только в основном процессе, шифруются через ОС (`safeStorage`) и вырезаются из логов и отчётов об ошибках. Если вы нашли место, где это нарушается, — это уязвимость.
