# История изменений

Предыдущие версии: [docs/changelog](docs/changelog).

## Release 1.0.0

- Окно **«Добавить моды»** вместо встроенной панели в карточке сборки: каталог Modrinth с популярными модами, поиском, 14 категориями, сортировкой и страницами; вкладка «Установлено» с удалением.
- Каталог строго по сборке: Fabric — моды Fabric, Forge — Forge, NeoForge — NeoForge, Quilt — Quilt и Fabric. Серверные моды не показываются.
- Исправлено: сборки с версией «последний релиз» / «последний snapshot» не находили моды — теперь версия определяется автоматически (и в каталоге, и при установке).
- Исправлено: сообщения об ошибках Modrinth, импорта модпаков и сборок больше не заменяются общим «Внутренняя ошибка лаунчера».
- Уведомления (тосты) показываются поверх модальных окон.
- **Новости**: карточка релиза 1.0.0 выделена (рамка, значок «НОВЫЙ РЕЛИЗ»); в боковой панели у «Новостей» горит точка, пока свежая запись не открыта.
- Тесты: 151 (новые — каталог, Quilt, категории, алиасы версий, IPC).
