# Участие в разработке

1. `npm install`, затем `npm test` (все тесты должны проходить).
2. Не добавляйте в renderer доступ к Node.js, токенам или файловой системе; всё идёт через `src/preload/preload.js` и `src/main/ipc.js`.
3. Новую ошибку добавляйте в каталог `src/main/errors.js` с кодом `OBS-xxx`, причиной и решением, затем обновите `docs/ERRORS.md`.
4. Не добавляйте обход лицензии или «пиратский» режим: проект работает только с официальным входом Microsoft.
5. Дизайн: матовый тёмный, один лаймовый акцент, без градиентов.
