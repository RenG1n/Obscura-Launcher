# Коды ошибок Obscura

Каждая ошибка получает номер `OBS-xxx`, показывается в окне лаунчера и сохраняется файлом в `%APPDATA%\Obscura\errors`. Файл содержит причину, способ исправления и технические детали (токены и пароли вырезаются).

Диапазоны: 1xx — сеть и установка (11x — загрузчики), 2xx — аккаунт, 3xx — Java и память, 4xx — процесс игры, 5xx — настройки и файлы, 9xx — внутренние.

| Код | Что случилось | Причина | Что делать |
|---|---|---|---|
| OBS-101 | Нет связи с серверами Mojang | Лаунчеру не удалось подключиться к серверу, с которого скачиваются файлы игры: нет интернета, адрес блокирует провайдер, антивирус или брандмауэр, либо включён неработающий VPN или прокси. | Проверьте интернет и отключите VPN/прокси на время установки. Выполните «npm run doctor» — он покажет, какой именно адрес не открывается. Добавьте Obscura в исключения антивируса и брандмауэра и повторите. |
| OBS-102 | Ошибка сертификата при загрузке | Соединение с сервером отклонено из-за недоверенного сертификата. Так бывает, если антивирус или программа безопасности подменяет HTTPS-трафик, либо на компьютере неверно выставлены дата и время. | Проверьте дату и время Windows. Временно отключите проверку HTTPS в антивирусе или добавьте Obscura в исключения, затем повторите. |
| OBS-103 | Сервер ответил ошибкой | Сервер Mojang или Microsoft получил запрос, но вернул код ошибки (например, 403 — доступ закрыт, 429 — слишком много запросов, 5xx — сбой на стороне сервера). | Подождите несколько минут и повторите. Если код 403 повторяется, адрес может быть закрыт для вашей сети или региона — попробуйте другой интернет. |
| OBS-104 | Не хватает места на диске | При записи файлов Windows сообщила, что на диске закончилось свободное место. Игре с ресурсами нужно около 1 ГБ. | Освободите место на диске с папкой %APPDATA% (обычно диск C:) и повторите установку. |
| OBS-105 | Нет прав на запись или файл занят | Windows не разрешила записать или изменить файл: папка защищена антивирусом («контролируемый доступ к папкам»), файл открыт другой программой или нет прав. | Закройте другие окна Minecraft, добавьте папку %APPDATA%\Obscura в исключения антивируса и повторите. |
| OBS-106 | Скачанный файл повреждён | Контрольная сумма скачанного файла не совпала с ожидаемой. Файл мог оборваться из-за нестабильного соединения. | Повторите установку: лаунчер перекачает только повреждённые файлы. Если повторяется — смените сеть. |
| OBS-107 | Версия Minecraft не найдена | Выбранной версии нет в официальном списке Mojang (она могла быть удалена или название введено неверно). | Выберите версию из списка в лаунчере. |
| OBS-108 | Не удалось получить список версий | Лаунчер не смог загрузить официальный список версий Minecraft, а сохранённой копии на диске ещё нет. | Проверьте интернет (и отключите VPN), затем перезапустите лаунчер. После первого успешного запуска список сохраняется и доступен без сети. |
| OBS-109 | Установка не создала файлы игры | Установка завершилась без ошибки, но нужные файлы версии не появились. Скорее всего, их удалил антивирус. | Добавьте %APPDATA%\Obscura в исключения антивируса и повторите установку. |
| OBS-110 | Загрузчик недоступен для этой версии | Для выбранной версии Minecraft нет официальной сборки Fabric или Forge (или выбранной версии загрузчика нет в списке). | Выберите другую версию Minecraft или другой загрузчик. Fabric обычно выходит для всех релизов, Forge — только для части версий. |
| OBS-111 | Не удалось установить загрузчик | Fabric или Forge не установился: сервер загрузчика недоступен, файл не прошёл проверку, либо установщик Forge завершился с ошибкой. | Повторите запуск. Если ошибка повторяется, откройте файл отчёта: в нём последние строки вывода установщика. Можно запустить игру без загрузчика (Vanilla). |
| OBS-112 | Адрес загрузки заблокирован защитой лаунчера | Сервер вернул адрес, которого нет в списке разрешённых (лаунчер скачивает файлы только с официальных серверов Mojang, Fabric, Forge и Adoptium). | Повторите позже. Если ошибка повторяется, отправьте файл отчёта: возможно, ваша сеть подменяет ответы серверов. |
| OBS-199 | Установка игры не удалась | Во время скачивания или установки произошла ошибка, которую лаунчер не смог отнести к известной причине. | Повторите установку. Если ошибка повторяется, отправьте файл отчёта из папки ошибок. |
| OBS-201 | Нужно войти в аккаунт Microsoft | Для запуска игры нужен вход в аккаунт Microsoft с купленной Minecraft: Java Edition. Вход ещё не выполнен или сессия истекла. | Нажмите «•••» у профиля слева внизу и войдите по коду. |
| OBS-202 | Не удалось войти в аккаунт | Вход через Microsoft/Xbox/Minecraft не завершился: код не был введён вовремя, вход отклонён или сервис вернул ошибку. | Повторите вход и введите код на странице microsoft.com/link в течение нескольких минут. Если ошибка повторяется, откройте файл отчёта — в нём точная причина. |
| OBS-203 | На аккаунте нет Minecraft: Java Edition | Аккаунт Microsoft вошёл успешно, но к нему не привязана лицензия Minecraft: Java Edition (или аккаунт детский и требует разрешения родителей в Xbox). | Войдите в тот аккаунт, на котором куплена игра, либо приобретите её на minecraft.net. Для детского аккаунта проверьте семейные разрешения Xbox. |
| OBS-204 | Вход уже выполняется | Окно входа уже открыто. | Завершите или отмените текущий вход. |
| OBS-205 | Нет связи с серверами Microsoft/Xbox | При входе лаунчер не смог подключиться к серверам Microsoft, Xbox или Minecraft. Причина — интернет, VPN, антивирус или блокировка адреса. | Проверьте интернет, отключите VPN и выполните «npm run doctor» — раздел «Доступность серверов» покажет, какой адрес закрыт. |
| OBS-301 | Не найдена подходящая Java | Для выбранной версии Minecraft нужна определённая Java, а на компьютере её нет: Minecraft 1.20.5 и новее требует Java 21, 1.18–1.20.4 — Java 17, 1.17 — Java 16, 1.16.5 и старше — Java 8. | Включите «Автоустановка Java» или нажмите «Установить» нужную версию в «Настройки → Java». Можно также установить Java 64-bit (например, Eclipse Temurin с adoptium.net) вручную. Найденные версии видно в «Настройки → Java». |
| OBS-302 | Недопустимый объём памяти | Выбранный объём оперативной памяти больше, чем можно выделить на этом компьютере (1 ГБ всегда остаётся системе), либо Java 32-bit не может использовать больше 1 ГБ. | Уменьшите ползунок памяти на главной странице. Для Java 32-bit установите 64-битную Java. |
| OBS-310 | Не удалось установить Java | Автоматическая загрузка Java (Eclipse Temurin с adoptium.net) не удалась: нет связи с серверами Adoptium/GitHub, файл не прошёл проверку SHA-256 или не хватило места. | Проверьте интернет и повторите. Если сеть ограничена, установите Java вручную (adoptium.net) или выберите java.exe в настройках. |
| OBS-311 | Скачанная Java не запускается | Java скачана и проверена, но не распаковалась или не запускается: антивирус мог заблокировать файлы либо в системе нет утилиты tar. | Добавьте %APPDATA%\Obscura в исключения антивируса и повторите установку в «Настройки → Java». Лаунчер использует tar (есть в Windows 10 1803 и новее) или PowerShell. |
| OBS-401 | Игра завершилась с ошибкой | Minecraft запустился, но закрылся с ненулевым кодом — произошёл сбой в самой игре или в её библиотеках. | Откройте файл отчёта: в нём последние строки вывода игры. Попробуйте другую версию Java, меньше памяти или переустановите версию. |
| OBS-402 | Java слишком старая для этой версии | Игра собрана для более новой Java, чем та, что запустила её (ошибка UnsupportedClassVersionError). | Установите Java нужной версии (см. «Настройки → Java») и повторите. |
| OBS-403 | Java не смогла стартовать | Виртуальная машина Java отказалась запуститься: чаще всего выбран слишком большой объём памяти или Java 32-bit. | Уменьшите объём памяти на главной странице и используйте Java 64-bit. |
| OBS-404 | Игре не хватило памяти | Minecraft исчерпал выделенную память (OutOfMemoryError). | Увеличьте объём памяти на главной странице (если позволяет компьютер) и закройте лишние программы. |
| OBS-405 | Не удалось запустить процесс Java | Windows не смогла запустить найденный файл Java: он удалён, повреждён или заблокирован антивирусом. | Переустановите Java и добавьте её в исключения антивируса. |
| OBS-406 | Игра уже запускается | Подготовка к запуску или сама игра уже работает. | Дождитесь окончания или нажмите «Отмена». |
| OBS-501 | Недопустимое значение настройки | Введено значение, которое лаунчер не принимает. | Выберите значение из допустимого диапазона. |
| OBS-502 | Изображение для фона отклонено | Файл не удалось прочитать как изображение или он слишком большой. | Выберите другое изображение (PNG, JPEG, WebP, GIF, BMP, AVIF, SVG). |
| OBS-900 | Внутренняя ошибка лаунчера | В самом лаунчере произошёл непредвиденный сбой. | Перезапустите лаунчер. Если ошибка повторяется, отправьте файл отчёта из папки ошибок. |
| OBS-901 | Необработанный сбой в лаунчере | В главном процессе лаунчера возникло исключение, которое никто не перехватил. | Перезапустите лаунчер и отправьте файл отчёта из папки ошибок. |
