Ник локального профиляОт 3 до 16 символов: латинские буквы, цифры и подчёркивание.
Аккаунты MicrosoftДобавляй несколько аккаунтов и переключай активный. Успешный вход подтверждает доступ к профилю Minecraft. Токены хранятся отдельно и шифруются средствами Windows.
